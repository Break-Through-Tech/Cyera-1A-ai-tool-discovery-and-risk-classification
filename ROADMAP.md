# Project Roadmap

**Target: demo-ready prototype by the end of November 2026.**

| Target | Milestone | Status / outcome |
|---|---|---|
| **Late October** | Discovery and classification backend | **Mostly complete:** data ingestion, tool identification, website evidence, AI detection, and category classification. |
| **Early November** | Complete backend findings | Finish risk assessment, save analysis results and evidence, and expose APIs for investigation. |
| **Mid-November** | Working dashboard | Upload data, view AI usage and risk summaries, filter findings, and inspect why tools were flagged. |
| **Late November** | Governance assistant and integration | Answer questions about usage and risk with supporting evidence; connect the full application. |
| **End of November** | Evaluation and demo-ready prototype | Test the complete workflow, fix issues, finalize documentation, and prepare the presentation. |

## Current Progress

As of October 27, the core analysis engine is largely built. The remaining work turns it into a complete, usable governance application.

Dates are proposed targets, not committed deadlines. Dashboard and assistant development can overlap once the backend result APIs are ready.
